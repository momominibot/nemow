What is Hormone Phase Locking?

Hormone phase locking is the process of precisely aligning physiological sensor data with the user's current hormonal phase. Instead of treating each day as an isolated data point, Nemow's phase-locking algorithm anchors every measurement to its position in the menstrual cycle — creating a phase-aware physiological model that adapts its interpretation and recommendations in real time.

⚡ The Locking Principle

A heart rate of 72 bpm means different things in different phases. In the follicular phase it might indicate normal recovery; in the luteal phase it could signal elevated sympathetic tone. Phase locking disambiguates these signals by providing the hormonal context for every physiological reading.

Real-Time ISF Tracking vs Static Blood Tests

Traditional hormone testing relies on blood draws — a single snapshot that misses the dynamic, pulsatile nature of hormone secretion. New technologies enable continuous interstitial fluid (ISF) tracking via microneedle patches, which sample hormone concentrations every 5–15 minutes through the skin.

The comparison:
  • Blood tests: High accuracy but point-in-time; capture only what's happening at that moment
  • ISF patches: Moderate accuracy per reading but continuous; capture the full waveform of pulsatile hormone secretion
  • PPG surrogate: No direct hormone measurement, but r ≥ 0.85 correlation with key hormonal state transitions via physiological proxies (HRV, RHR, temperature)
🔬 The r ≥ 0.85 Threshold

Nemow's phase-locking algorithm achieves a cross-correlation coefficient of r ≥ 0.85 between PPG-derived autonomic markers and expected hormonal state. This is the validation threshold at which autonomic signals can reliably substitute for direct hormone measurement for the purpose of phase classification.

The Nemow Phase-Locking Pipeline
  1. Raw signal ingestion — PPG waveform, accelerometer, temperature at 50 Hz
  2. Feature extraction — Nocturnal RHR, rMSSD, respiratory rate, skin temperature baseline
  3. Phase probability estimation — Bayesian model assigns probability to each cycle phase
  4. Temporal smoothing — Hidden Markov model enforces phase transition constraints
  5. Output — Daily phase classification with confidence score + 24-hour retrospective update
The pipeline runs nightly, processing the previous night's data and updating the phase classification before you wake up.
